# 沟通工具

沟通工具位于“规划与执行 / 沟通工具”（`/app/communication`），用于个人进度记录和内容整理，不会自动加好友、发送消息、发送日历邀请或读取外部联系人。

- **加好友记录**：按平台、账号和群保存顺序/逆序、最后申请的人、申请话术、通过后第一句话和备注。更新进度只覆盖最新进度，不生成历史快照；记录可以归档或恢复。
- **话术库**：按当前账号维护的自定义类型整理标题、标签和一个或多个正文段落。初始没有预置类型，可新增、改名和删除类型；删除正在使用的类型前，需要先调整相关话术。正文是纯文本，复制全部时按段落顺序用空行连接。
- 记录和话术都以当前登录账号隔离；删除话术不会影响加好友记录。

加好友记录里的申请话术和第一句话是该记录的手工内容，不会引用话术库。复制功能优先使用 Clipboard API，并在 HTTP 等受限环境使用用户触发的文本选择回退；失败时会提示手动复制。
