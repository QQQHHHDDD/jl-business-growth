## 二、阶段目标

验证：
1. V1 核心业务闭环整体可用；
2. 权限和数据隔离安全；
3. 导入导出可靠；
4. 收入模拟与 Excel 兼容；
5. 文件、团队、财务、删除、时区逻辑正确；
6. 桌面和移动端可用；
7. 50 用户量级不存在明显性能问题；
8. 是否具备进入 Release Candidate 和生产部署演练条件。

## 三、冻结规则

严格执行：
- 不新增 V1 功能；
- 不擅自改变业务规则；
- 不因失败删除断言；
- 不降低测试标准；
- 不跳过失败测试；
- 不改生产环境；
- 不部署云服务器；
- 不使用真实生产密钥。

允许：修 Bug、权限漏洞、数据一致性问题、严重 UX，补测试和测试辅助脚本。

## 四、测试数据

自动化测试必须使用独立测试数据库、测试账号和测试文件，不污染开发真实数据。执行破坏性测试前使用现有测试数据库保护机制确认目标数据库。

## 五、必须执行

### A. 基础验证

```bash
make generate
make lint
make test
make build
make check
make test-integration
make test-e2e
git diff --check
make migrate-status
make migrate-test-status
```

如果 Makefile 已变化，以仓库当前命令为准，并在报告说明。

### B. 权限专项
创建 User A、User B、Admin、Super Admin，验证：
- A 不可访问 B 的任何业务对象或文件；
- User 不可访问 Admin API；
- Admin 不可查看普通用户业务数据；
- Admin 不可管理 Super Admin；
- 禁用/删除账号后旧 Session 失效；
- DELETING 账号不可继续写入。

### C. Dashboard
验证今日、本周、本月、目标、日程、团队、学习、财务全部来自真实测试数据，不得硬编码 mock。

### D. 梦想/目标
梦想图片、替换、解除、删除清理；父子目标；数字指标；自动完成度；关系图。

### E. 工作量/营业额
补录、修改、删除、五层规则、顾客跟进、学习时长、PV/净营业额互转和聚合。

### F. 日历
重复日程、单次/后续/整系列修改、ICS、mail outbox、时区、DST、跨月。**本阶段不要配置真实 SMTP。**

### G. 团队
member_code、parent_member_code、三层以上关系、月末快照、用户 IANA 时区、DST、延迟补跑、captured_late、幂等、历史快照。

### H. 知识附件
PDF/TXT/Markdown/图片上传、关联、预览、解除、删除和权限隔离。

### I. 财务
重点验证：API 十进制字符串、Go 内部整数分、PostgreSQL numeric、前端显示、导入导出、预算、现金流、分析。不得出现浮点金额误差。

### J. 收入模拟
使用公式映射和 Golden Test，覆盖：
- 边界值
- 6000/8000/10000 档位
- 封顶
- 双年奖金所有等级
- 多市场
- 零值/高值

必须与 Excel 兼容逻辑一致。

### K. 导入幂等
- 工作量同日 upsert
- 营业额同日 upsert
- 团队 member_code upsert，parent_member_code 恢复关系
- 财务重复指纹默认 skip
- COMMITTED 任务再次提交必须拒绝
- 相同 SHA-256 提示历史记录
- 分类/父节点/日期/金额/PV 错误尽量在预览阶段发现

### L. 导出恢复
执行 TEAM 三层结构“导出→清空测试数据→重新导入→比较层级”，确认层级完整恢复；完整 ZIP 检查数据、图片和文档。

### M. 账户删除
用户自删和管理员删用户必须走统一清理逻辑，验证 Session、DB、文件、失败记录、重试、DELETING 和并发写请求。

### N. 故障测试
执行受控异常：数据库不可用、邮件失败、非法/超大文件、网络失败、API 重启、重复提交。不得破坏数据。

## 六、基础性能测试

实现可重复执行的轻量测试：50 个模拟用户执行登录、Dashboard、工作量查询/写入、营业额、分析、搜索。

记录：
- 总请求数
- 成功率/5xx
- P50/P95
- CPU/内存
- DB 连接
- 慢查询

不要追求极限 QPS，只确认 10～50 用户规模无明显瓶颈。

## 七、缺陷处理

2. 分级 P0/P1/P2/P3；
3. 记录复现；
4. 修复；
5. 补回归测试；
6. 重跑相关测试；
7. 最后跑全量测试。

P0/P1 未清零不得宣布综合测试完成。
