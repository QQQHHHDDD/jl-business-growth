## 2. C1～C5、D1～D3 完成内容

### C1 财务

- 建立“总览 / 流水 / 预算 / 资金快照”四个视图。
- 总览使用现有真实流水、预算和分类数据展示本月收入、支出、净现金流和预算使用情况。
- 新增流水、预算和资金快照改为按需打开的 Sheet，分类管理降级为次级折叠操作。
- 保留现有金额精度、分类类型和财务业务模型。

### C2 学习中心

- 建立“学习项目 / 附件库”两个视图，并增加基于现有数据的学习摘要。
- 增加关键词、类型、状态和标签筛选。
- 新增与编辑学习项目统一使用 Sheet；附件库集中展示现有文件并保留预览、关联和删除规则。

### C3 收入模拟

- 建立“模拟器 / 保存方案 / 方案比较”三个视图。
- 输入项按基础数据、市场结构和奖励条件分组。
- 桌面结果区使用 sticky 布局，移动端自然降级；保存、复制、比较和删除方案入口全部保留。
- 未修改收入公式、输入字段语义或金额计算逻辑。

### C4 复盘

- 建立“每日 / 每周 / 每月”三个视图。
- 将当前周期经营摘要与文本复盘整合到同一工作区。
- 使用现有单周期接口提供最近周期快捷访问，没有改变周期唯一规则和摘要数据来源。

### C5 数据统计

- 建立“工作量 / 营业额 / 目标 / 团队 / 财务”五个领域视图。
- 提供“本周 / 本月 / 本年 / 自定义”时间范围。
- 各领域统一为 KPI、趋势、结构和明细布局，只使用现有 analytics API 返回字段。

### D1 导入/导出与设置

- 导入流程整理为“类型 → 模板 → 上传 → 校验预览 → 确认”的五步结构。
- 导出改为紧凑的数据类型列表，保留现有导出能力。
- 设置建立“账号 / 偏好 / 数据与安全”三个视图，危险操作独立展示。

### D2 全局搜索

- Phase A 顶部搜索入口改为 Search Overlay，支持 220ms 防抖、按模块分组、上下键选择和 Enter 打开。
- “查看全部结果”进入 `/app/search`，完整搜索页保留模块筛选和结果列表。
- 搜索范围严格沿用现有后端能力，没有新增实体类型或扩大权限范围。

### D3 响应式与视觉一致性

- 统一 PageHeader、Panel、Tabs、Dialog、Sheet、Table 和页面容器的宽度、滚动、间距与换行约束。
- Tabs 在窄屏可横向滚动；表格保持最小可读宽度；Dialog 和 Sheet 在视口内独立滚动。
- 页面容器阻止非预期的页面级横向溢出，Sheet 底部操作区适配移动端安全区域。
- 加强管理员移动端和剩余业务页的响应式回归测试。

## 11. 已知 UI 技术债务

- 全局搜索结果当前进入对应模块页面，而不是具体记录详情；现有业务路由不支持实体 ID 深链接，本轮按功能冻结要求未新增路由或后端能力。
- 复盘的“最近周期”由前端计算周期日期并调用现有单周期接口，不是后端历史列表；当前没有历史列表 API。
- 数据统计趋势继续使用轻量 CSS 图形，没有提前引入新的图表依赖；数据来源和统计口径保持不变。
- 自动化验证了结构、交互、可访问名称和横向溢出约束，视觉审美、真实数据密度、浏览器缩放和真机触控仍需产品负责人进行人工验收。

以上项目均不阻塞本轮 UI 重构完成，其中前两项若要改为记录级深链接或真实历史列表，需要另行确认产品范围并设计 API，不应在本轮纯前端重构中处理。
