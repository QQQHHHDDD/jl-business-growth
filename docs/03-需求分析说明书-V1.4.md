# JL团队生意成长管理系统——需求分析说明书 V1.4

- 文档阶段：第3阶段 需求分析
- 状态：已确认
- 更新日期：2026-09-13

## 1. 用户角色

### 普通用户

管理自己的梦想、目标、工作量、营业额、日历、团队、学习、财务、收入模拟和复盘。

### 普通管理员

只管理普通用户与邀请码，不读取任何普通用户业务内容。

### 超级管理员

拥有普通管理员全部权限，并额外拥有管理员账号的增删改查能力。管理员账号管理集成于现有管理员端。

## 2. 账号与注册

- 普通用户必须邀请码注册；
- 登录凭证为“账号 + 密码”；
- 不要求邮箱；
- 不提供邮件找回密码；
- 用户登录后可修改密码；
- 管理员可以重置普通用户密码；
- 超级管理员可以管理普通管理员；
- 同一浏览器允许保存多个普通用户登录状态并快速切换。

## 3. 邀请码

支持：

- 多次使用；
- 最大使用次数；
- 无限次数；
- 指定过期时间；
- 永不过期；
- 启用/停用；
- 使用次数统计。

## 4. 首页

首页同时承担“今日行动”和“数据驾驶舱”作用，聚合：

- 今日安排；
- 主要目标；
- 本日/本周/本月工作量；
- 营业额；
- 财务摘要；
- 团队规模；
- 学习状态；
- 复盘入口。

## 5. 梦想与目标

梦想支持：标题、描述、图片、排序，并可选关联目标。

目标层级：

- 长期；
- 年度；
- 阶段/大会；
- 月；
- 周；
- 日。

目标支持可选父目标，形成目标分解树；支持量化指标，并根据实际业务记录自动计算完成度。

目标可视化需要重点做好，至少提供清晰、美观的目标树/路线图和进度表达。

## 6. 每日工作量

每日记录：

- 开启对话；
- 深入对话；
- Buffer；
- 分享故事；
- 筛选；
- 提供机会；
- 会面；
- 顾客跟进；
- 读书分钟；
- 听音频分钟；
- 营业额；
- 备注。

同一个候选人同一天经过多个阶段时，各阶段均 +1。

历史允许随时补录和修改。

读书/听音频与学习中心共享底层数据，营业额与营业额模块共享底层数据，不重复保存相互冲突的副本。

## 7. 营业额

- 同时展示 PV 和净营业额；
- 固定换算：1 PV = ¥12.5；
- 输入任意一项可同步换算；
- 营业额是业务指标，不等于真实现金收入。

## 8. 日历

内部日历支持：

- 月/周/日视图；
- 全天或时间段事件；
- 标题、地点/会议链接、说明；
- 单次日程；
- 重复日程：每天、每周、每月、每年、自定义每 N 天/周/月；
- 修改重复事件时支持“仅这一次 / 这一次及以后 / 整个系列”；
- 删除重复事件时同样支持范围选择。

邮件邀请：

- 填写一个或多个受邀邮箱；
- 发送标准 ICS 邀请；
- 修改后可发更新；
- 删除后可发取消；
- 用户可选择仅修改本地日历、不发送邮件。

V1 不做 Google Calendar 双向同步和 RSVP 状态同步。

## 9. 团队

团队节点字段：

- 姓名/昵称；
- 推荐人；
- 加入日期；
- 当前级别；
- 城市；
- 备注；
- 活跃状态。

系统维护当前团队树，并在每月最后一天自动保存结构快照；允许用户随时手动保存快照。历史快照生成后不随当前结构变化。

## 10. 学习与知识

学习记录支持：

- 标题；
- 类型；
- 手工录入的原始文字；
- 笔记；
- 我的理解；
- 行动项；
- 标签；
- 学习日期；
- 来源链接；
- 完成状态；
- 学习进度。

学习类型至少包括：音频、视频、书籍、大会、会议、PHP、导师分享、产品、其他。

“音频/视频”类型只代表学习来源，不上传音视频文件。

### 文件上传

V1 支持：

- PDF；
- TXT；
- Markdown；
- JPG/PNG/WebP 图片。

V1 不支持：

- DOCX；
- 音频；
- 视频。

上传文件只保存原文件并支持网页预览，不自动提取正文、不 OCR、不自动转换为知识文本。

## 11. 全局搜索

支持模糊搜索：

- 学习/知识标题；
- 用户手工录入文本；
- 笔记、理解、行动项、标签；
- 目标；
- 日历；
- 团队成员。

不搜索上传文件内部正文。

## 12. 财务

采用简化财务模型，不管理银行卡/支付宝等“账户余额账本”。

支持：

- 生意收入；
- 工资等主要收入；
- 产品、大会、培训、交通、住宿、工具等支出；
- 月预算；
- 实际支出；
- 净现金流；
- 储蓄；
- 应急资金；
- 相关目标。

## 13. 收入模拟

以项目文件《收入模拟器.xlsx》的实际公式为计算基准。

支持：

- 最多 12 个市场；
- 个人使用 PV；
- 客户 PV；
- 相关资格和达标状态；
- 个人营业额奖金；
- 6% 优惠券；
- 差额奖金；
- 绩优营销之星月度奖励；
- 营销之星年度成长奖励；
- 红宝石奖金；
- 基础骨干奖金；
- 精英骨干奖金；
- 双年奖金。

用户可以保存、命名、修改、复制、删除和比较方案。

展示分类：

- 预计月度收入；
- 一次性/年度奖励；
- 合计预计收入。

## 14. 复盘

每用户：

- 每自然日最多 1 份每日复盘；
- 每自然周最多 1 份周复盘；
- 每自然月最多 1 份月复盘。

均可反复修改。

## 15. 模板导入

V1 Excel 模板导入范围：

- 每日工作量；
- 财务流水；
- 团队成员；
- 营业额历史。

流程：下载模板 → 填写 → 上传 → 校验 → 预览 → 确认导入。

不承诺兼容用户自制任意 Excel 格式。

## 16. 导出

支持：

- CSV/XLSX 结构化数据；
- Markdown/JSON 知识数据；
- 完整账户 ZIP 导出，包含结构化数据、用户上传的文档和图片。

## 17. 时区

- 默认 `Asia/Shanghai`；
- 用户可自行修改；
- 日历时间按用户/事件时区处理；
- 每日记录和复盘使用明确的“本地业务日期”，不简单用 UTC 日期替代。

## 18. 数据删除

用户或管理员删除普通用户账号后：

- 在线账号立即失效；
- 在线业务数据立即删除；
- 在线上传文件删除；
- 所有会话失效；
- 历史备份中的旧数据按备份生命周期自然过期。

## 19. 安全与隔离

- HTTPS；
- 密码安全哈希；
- 后端强制用户数据隔离；
- 管理员不能查看业务数据；
- 文件下载/预览必须鉴权；
- 数据库和文件定期备份；
- 密码、Session Token 不写日志。

## 20. V1 明确不做

- 候选人 CRM；
- 外部聊天自动同步；
- Google Calendar 双向同步；
- 团队账号数据共享；
- AI；
- 音视频上传和转写；
- DOCX 上传；
- 文档正文提取/OCR；
- 银行自动同步；
- 原生 App；
- 微服务。


## 开发与生产环境要求

系统至少区分：

- `development`：内网日常开发；
- `test`：自动化测试；
- `production`：云服务器正式环境。

三种环境的数据、文件和敏感配置必须隔离。开发/测试环境不得真实发送日历邀请邮件给外部用户，除非开发者显式切换测试配置。
