# 收入模拟器 Excel 公式映射 V1.0
> 来源：项目文件 `收入模拟器.xlsx` 的“收入模拟器”工作表。实现时以这些实际公式的行为为兼容基准，不根据指南文字自行修正。
## 已识别输入项
| Excel 单元格/区域 | 含义 | Web 字段建议 |
|---|---|---|
| `E7` | 个人使用 PV | `personal_use_pv` |
| `E8` | 客户营业额 PV | `customer_pv` |
| `N8` | 营销之星年度成长奖励状态：保持 / 成长 / 未达标 | `annual_growth_status` |
| `N9` | 本财年达标次数 | `annual_growth_qualified_months` |
| `M11` | 基础骨干奖金：是否符合周期（YES/NO） | `bfi_period_eligible` |
| `M13` | 精英骨干奖金：是否符合周期（YES/NO） | `bbi_period_eligible` |
| `D21,G21,J21,M21,P21,S21,D28,G28,J28,M28,P28,S28` | 市场 1–12 PV | `markets[0..11].pv` |
| `L15` | 营业额换算比例，固定 12.5 | `pv_to_net_amount_rate` |

## 输出字段映射
| Excel 单元格 | 含义 | Web 字段建议 |
|---|---|---|
| `S7` | 个人营业额奖金 | `personal_sales_bonus` |
| `S8` | 6%优惠券 | `coupon_6_percent` |
| `S9` | 差额奖金 | `differential_bonus` |
| `S10` | 绩优营销之星月度奖励 | `monthly_marketing_star_bonus` |
| `S11` | 营销之星年度成长奖励 | `annual_growth_bonus` |
| `S12` | 红宝石奖金 | `ruby_bonus` |
| `S13` | 基础骨干奖金 | `bfi_bonus` |
| `S14` | 精英骨干奖金 | `bbi_bonus` |
| `T3` | Excel 本月总收入（S7:S14 合计） | `excel_total_income` |

## 兼容性注意事项
- `S10` 按 Excel 实际公式：6000–7999 为 1.30%，8000–9999 为 1.35%，10000+ 为 1.45%，并封顶 3000 元。
- `S8` 的 Excel 条件为 `E9>100`，不是 `>=100`；Web V1 按 Excel 行为复刻。
- 市场 2、3 的 3% 档在 Excel 中从 100 PV 起；多数其他市场从 200 PV 起。V1 不自行统一阈值。
- 大于等于 10000 PV 市场的差额奖金分支存在按具体市场位置编写的特殊公式；V1 应逐市场复刻而不是先抽象成“看起来更合理”的通用公式。
- `S11` 年度成长奖励在原 Excel 的 `T3` 中被计入合计。Web 产品展示时将其归为“一次性/年度奖励”，但仍保留 `excel_total_income` 用于与 Excel 对账。
- 双年奖金来自“表3”图片，不属于上述单元格公式；Web 单独作为一次性/年度奖励计算。
