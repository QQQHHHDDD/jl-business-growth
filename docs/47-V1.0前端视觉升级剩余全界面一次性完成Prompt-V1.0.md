# JL团队生意成长管理系统——V1.0 前端视觉升级剩余全界面一次性完成 Prompt V1.0

## 0. 任务定位

当前前端视觉升级已经完成并人工确认：

- UI-A：Design System + App Shell
- UI-B1：数据统计 `/app/analytics`
- UI-B1 最终精修

**数据统计页视觉语言正式冻结，作为全系统剩余页面的主基准。**

本轮目标：

> **在一轮任务中完成所有剩余前端页面的视觉升级。**

注意，“一轮完成”不等于“无序批量改”。请在同一个任务内按内部批次推进、逐批自检，但最终一次性交付所有剩余页面，不再等待中间人工确认。

本轮重点是视觉统一，不是产品重构。

---

# 1. 已冻结视觉语言

以下视觉原则来自已通过人工验收的数据统计页，后续页面优先复用，不再重新发明另一套设计系统：

- 青绿品牌主色；
- 冷白 / 浅蓝灰 canvas；
- 轻柔 pastel 辅助色；
- 18–20px major card 圆角；
- 10–12px controls；
- 柔和阴影；
- 弱边框；
- 清晰的 canvas → normal surface → important surface 层级；
- rounded segmented controls；
- 彩色但克制的 MetricCard；
- 轻量原创成长主题 SVG；
- 品牌化 Empty State；
- 现代化 DataTable；
- 青春、有活力、有成长感，但不儿童、不游戏化；
- 不靠满屏渐变，不靠高饱和彩虹色；
- 不使用页面切换动画。

**数据统计页 Hero、KPI tone、Tabs、时间范围、Card、EmptyState、DataTable 作为视觉标杆。**

不得为了其他页面重新设计一套互相冲突的语言。
