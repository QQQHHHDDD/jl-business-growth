## 9. 团队数据一致性

- 当前成员数和当前启用成员数直接查询当前 `team_members` 状态。
- 所选周期快照数来自 `team_snapshots`。
- 趋势使用每个快照月份的最新一次快照及其成员明细。
- 没有快照时不再用当前团队数据伪造历史趋势。
- 集成测试覆盖无快照的当前计数及多快照顺序和隔离边界。

因此同一时刻团队页与团队统计页的当前人数口径一致。

## 10. 搜索深链接

已实现并验证以下形式：

```text
/app/goals?goal=<id>
/app/calendar?event=<id>
/app/team?member=<id>
/app/knowledge?item=<id>
/app/knowledge?tag=<tag>
```

目标、日历、团队和学习页面会在刷新后读取 URL 并恢复具体记录。页面使用 React Router 链接，返回搜索页时保留查询状态。具体记录仍通过当前用户权限下的查询加载，猜测其他账号 ID 不能绕过后端隔离。
