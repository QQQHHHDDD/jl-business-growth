## 本轮关键修订

1. 正式接受部分不影响产品行为的工程实现差异：集中目录、UUID 扁平文件存储、后端 Go 版本化规则 map、固定模板最小 XLSX 实现；
2. 明确上述接受不等于删减产品需求；
3. 重复导入规则正式确定：工作量/营业额按日期 upsert，团队按稳定 `member_code` upsert，财务重复默认跳过，已提交任务不可再次提交；
4. 明确梦想图片、知识附件、团队时区快照、管理员删除物理文件、TEAM 层级导出、金额精度等为 V1 发布阻塞项；
5. 图表要求保留“数据可视化效果”，但不再强制 Apache ECharts 作为产品要求；
6. Phase 0–6 主开发 Prompt 转为历史开发基线，当前编码应使用 V1 收口 Prompt。
7. V1 收口新增 migration `00008_v1_closure.sql`，完成文件关联、团队稳定编码、导入幂等、账户文件清理和金额精度边界。
